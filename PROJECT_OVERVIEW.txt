----------------------------------------------------------------
  WHAT IS SHIELD?
----------------------------------------------------------------

SHIELD is a web-based credit risk evaluation tool built for a
fictitious Malaysian commercial bank called JuneBank. It is
designed to help Loan Officers assess the financial health of
Small & Medium Enterprises (SMEs) applying for business loans.

The officer enters 20 normalised financial ratios for an SME,
and SHIELD instantly predicts the probability of financial
default using a trained machine learning model. Alongside the
risk score, it generates a SHAP-based explainability breakdown
(showing which financial factors drove the decision) and an
AI-written advisory report tailored to the specific case.

Every evaluation is logged to a PostgreSQL database, creating
a full audit trail that the officer can review at any time.

Academic context : Final Year Project (FYP) / Degree Project
                   For demonstration and academic use only.
Dataset          : Italian company bankruptcy dataset (2023)
                   ~96,000 companies, 20 financial ratio features


----------------------------------------------------------------
  THE PROBLEM IT SOLVES
----------------------------------------------------------------

Traditional SME credit assessment is slow, manual, and
inconsistent between loan officers. SHIELD addresses this by:

  - Standardising evaluation using a quantitative ML model
  - Explaining WHY a company is high or low risk (SHAP)
  - Generating natural-language advisory text automatically
  - Keeping a persistent audit log for every decision made
  - Giving the loan officer a clean, professional report to
    attach to the loan file (PDF export)


----------------------------------------------------------------
  KEY FEATURES
----------------------------------------------------------------

  Prediction Engine
  • Random Forest binary classifier (bankruptcy / no bankruptcy)
  • Top 20 Information Gain features as input (normalised [0,1])
  • Outputs probability of default (0–100%) + risk class
  • Risk gauge visualisation (green / amber / orange / red)

  Explainability
  • SHAP TreeExplainer runs per-request
  • Top 5 risk drivers and protective factors shown
  • Horizontal bar chart of SHAP values per feature

  AI Advisory Report
  • Groq API (LLM) generates dynamic credit analysis prose
  • System prompt: "Senior Credit Risk Analyst at JuneBank"
  • Covers: risk drivers, protective factors, recommendation
  • Falls back to rule-based text if API is unavailable

  Audit & Logs
  • Every evaluation saved to PostgreSQL automatically
  • /logs page shows full history with expandable rows
  • Each row shows: company, SSM no., loan amount, evaluator,
    date, risk classification, P(default), SHAP breakdown

  PDF Reports
  • Per-evaluation report: JuneBank A4 letterhead template
  • Personal Analytics report: officer's own performance stats

  Personal Analytics Dashboard (/dashboard)
  • KPI ribbon: total SMEs, volume processed, risk rates
  • Donut chart: risk distribution (High / Low)
  • Bar chart: evaluations per day (last 7 active days)
  • Recent pipeline table: last 5 evaluations

  Settings & Support
  • /settings — profile name, employee role, password change
  • /contact  — IT support ticket form + PIC directory card


----------------------------------------------------------------
  MACHINE LEARNING MODEL
----------------------------------------------------------------

  Algorithm      : Random Forest Classifier
  Task           : Binary classification
                   (1 = bankrupt / high risk, 0 = healthy)
  Train/Test     : 80/20 split with 10-fold cross-validation
  Saved as       : model/SHIELD_BestModel_RF_8020_CV10.joblib

  Feature Selection : Top 20 features ranked by Information Gain
                      (removed Net Value Per Share (C) and
                       Total Income/Total Expense; added
                       Degree of Financial Leverage (DFL) and
                       ROA(B) Before Interest & Depreciation
                       After Tax)

  Input Features (20 normalised financial ratios, all in [0,1]):
  ---------------------------------------------------------------
   1. Persistent EPS in the Last Four Seasons
   2. Net Profit Before Tax / Paid-in Capital
   3. Borrowing Dependency
   4. Per Share Net Profit Before Tax
   5. Net Income to Stockholder's Equity
   6. ROA(A) — Before Interest & % After Tax
   7. Net Income to Total Assets
   8. Interest Expense Ratio
   9. Interest Coverage Ratio (Interest Expense to EBIT)
  10. Continuous Interest Rate (After Tax)
  11. Degree of Financial Leverage (DFL)
  12. ROA(C) — Before Interest & Depreciation Before Interest
  13. Retained Earnings to Total Assets
  14. Debt Ratio %
  15. Net Value Per Share (A)
  16. Net Worth / Assets
  17. Equity to Liability
  18. Net Value Per Share (B)
  19. ROA(B) — Before Interest & Depreciation After Tax
  20. Liability to Equity

  Explainability : SHAP (SHapley Additive exPlanations)
                   TreeExplainer (interventional perturbation)
                   Runs once per prediction request
                   Returns per-feature contribution values
                   Positive SHAP = pushes toward high risk
                   Negative SHAP = protective / lowers risk
                   check_additivity=False applied to suppress
                   benign floating-point warnings from large
                   RF ensembles (values remain accurate)

  Preset Profiles (for demo/testing):
    Profile A — Healthy SME    (low default probability)
                High profitability, strong equity, low debt
    Profile B — Distressed SME (high default probability)
                Low profitability, low equity, high debt
    Median    — All features at dataset median values

----------------------------------------------------------------
  ENVIRONMENT VARIABLES  (backend/.env)
----------------------------------------------------------------

  MODEL_PATH      Path to .joblib model file
  CORS_ORIGINS    Allowed frontend origins (comma-separated)
  HOST            Uvicorn host  (default: 0.0.0.0)
  PORT            Uvicorn port  (default: 8000)
  LOG_LEVEL       debug / info / warning / error
  GROQ_API_KEY    Optional — free key from console.groq.com
                  Absent → rule-based advisory fallback
  DATABASE_URL    Optional — PostgreSQL connection string
                  Absent → no persistence, app still works
