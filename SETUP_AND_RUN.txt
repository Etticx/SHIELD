PREREQUISITES
================================================================

Python:
  - Python 3.10 or higher
  - Download from https://www.python.org/downloads/
  - During install, check "Add Python to PATH"

Node.js (for the new frontend only):
  - Node.js 18 or higher (includes npm)
  - Download from https://nodejs.org/
  - Verify: node --version  and  npm --version

OPTION A — New Enterprise App (FastAPI + Next.js)
================================================================
This runs the full decoupled v2 setup: a Python API backend
and a React/Next.js frontend. Requires two terminals running
at the same time.

------------------------------------------------------------
TERMINAL 1 — Backend (FastAPI)
------------------------------------------------------------

STEP 1: Navigate to the backend folder

    cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD\backend"


STEP 2: Create a virtual environment (first time only)

    python -m venv venv


STEP 3: Activate the virtual environment

    venv\Scripts\activate

    You will see (venv) at the start of your prompt.


STEP 4: Install backend dependencies (first time only)

    pip install -r requirements.txt

    This installs: fastapi, uvicorn, pydantic, xgboost,
                   shap, joblib, pandas, numpy, python-dotenv


STEP 5: Configure environment (first time only)

    copy .env.example .env

    Open .env in a text editor. The default values work
    for local development — no changes needed to start.

    ── Optional: Enable AI-Powered Advisory (Groq) ────────────────────
    SHIELD's advisory engine uses Groq (openai/gpt-oss-120b) to
    generate dynamic, natural-language credit risk explanations.

    To enable it:

    1. Get a FREE API key from Groq Console (no billing required):
           https://console.groq.com

    2. Open backend/.env and add your key:
           GROQ_API_KEY=your_key_here

    3. Restart the backend — that's it.

    Why Groq?
      • ~500 t/s on Groq's LPU hardware
      • Free plan: 1,000 requests/day, 200K tokens/day
      • openai/gpt-oss-120b — flagship model, high quality output
      • 131k context window, no billing required

    Free plan rate limits (openai/gpt-oss-120b):
      • 30 requests/minute
      • 1,000 requests/day
      • 8,000 tokens/minute
      • 200,000 tokens/day

    If GROQ_API_KEY is missing, empty, or the API call fails for
    any reason, SHIELD automatically falls back to the built-in
    rule-based advisory engine. The app never crashes or stalls.
    The AdvisoryReport panel shows a "Groq AI" or "Rule-based"
    badge so users can see which engine generated the text.
    ────────────────────────────────────────────────────────────────────


STEP 6: Start the API server

    python run.py

    API is now running at:   http://localhost:8000
    Interactive API docs at: http://localhost:8000/docs

    Leave this terminal open and running.

================================================================
TROUBLESHOOTING
================================================================

Problem : "python is not recognized"
Fix     : Python is not on your PATH. Reinstall Python and
          check "Add Python to PATH" during setup.

Problem : Backend venv\Scripts\activate not recognised
Fix     : Make sure you are inside the backend/ folder,
          not the SHIELD root.
          Run: cd "...\SHIELD\backend"

Problem : "npm is not recognized"
Fix     : Node.js is not installed. Download from https://nodejs.org/

Problem : Frontend shows "Failed to fetch" or API errors
Fix     : Make sure the backend is running in Terminal 1 first.
          Check http://localhost:8000/health — it should return:
          {"status":"healthy","model_loaded":true,...}

Problem : Backend crashes — model file not found
Fix     : Confirm xgb_shield_model.joblib is in SHIELD/model/
          Check MODEL_PATH in backend/.env points to the right path.
          Default value: ../model/xgb_shield_model.joblib

Problem : Port 8000 already in use (backend)
Fix     : Edit backend/.env and change PORT=8000 to PORT=8001
          Then update frontend/.env.local:
          NEXT_PUBLIC_API_URL=http://localhost:8001

Problem : Port 3000 already in use (frontend)
Fix     : Next.js will automatically try port 3001, 3002 etc.
          Check the terminal output for the actual URL.

Problem : Port 8501 already in use (Streamlit)
Fix     : streamlit run app.py --server.port 8502

Problem : SHAP errors or slow first prediction
Fix     : The SHAP explainer is built once on backend startup.
          The first POST /predict call may take a few seconds.
          Subsequent calls will be faster.


================================================================
API QUICK REFERENCE (v2 backend)
================================================================

GET  http://localhost:8000/health
     → Checks model and explainer are loaded

GET  http://localhost:8000/features
     → Returns all 20 feature labels, median defaults,
       and both test profiles (healthy / distressed)

POST http://localhost:8000/predict
     → Body: JSON with 20 float fields (see README.md)
     → Returns: probability, classification, SHAP values,
                advisory report

Full interactive docs: http://localhost:8000/docs
