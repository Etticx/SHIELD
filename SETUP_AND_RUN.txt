================================================================
  SHIELD — SME Health Indicator and Evaluator for Loan Decision
  Setup & Run Guide
================================================================

PREREQUISITES
-------------
- Python 3.10 or higher installed on your machine
- All project files in place:
    SHIELD/
    ├── app.py
    ├── requirements.txt
    ├── data/
    │   ├── df_cleaned_original.csv
    │   └── X_train_processed_8020.csv
    └── model/
        └── xgb_shield_model.joblib


================================================================
STEP 1 — Open Terminal in the SHIELD Root Folder
================================================================

Option A (Recommended):
  - Open the SHIELD folder in VS Code
  - Press Ctrl + ` to open the integrated terminal

Option B:
  - Open Windows Command Prompt or PowerShell
  - Navigate to your project folder:
      cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD"


================================================================
STEP 2 — Create a Virtual Environment
================================================================

Run this command once (you only need to do this one time):

    python -m venv venv

This creates a folder called "venv" inside your SHIELD directory.
It is your isolated Python environment for this project.


================================================================
STEP 3 — Activate the Virtual Environment
================================================================

Run this every time you open a new terminal to work on SHIELD:

    venv\Scripts\activate

You will see (venv) appear at the start of your terminal prompt.
This confirms the environment is active.

    Example:  (venv) d:\...\SHIELD>


================================================================
STEP 4 — Install All Required Packages
================================================================

Run this once (or again if you ever recreate the venv):

    pip install -r requirements.txt

This installs:
  - streamlit       (web app framework)
  - pandas          (data handling)
  - numpy           (numerical operations)
  - xgboost         (the trained model)
  - shap            (explainability)
  - joblib          (loading the .joblib model file)
  - matplotlib      (SHAP plots)

Wait for all packages to finish installing before moving on.


================================================================
STEP 5 — Run the SHIELD App
================================================================

    streamlit run app.py

The app will automatically open in your default browser at:

    http://localhost:8501

If it does not open automatically, copy that URL into your browser.


================================================================
STOPPING THE APP
================================================================

Go back to the terminal and press:

    Ctrl + C

This stops the Streamlit server.


================================================================
EVERY TIME YOU COME BACK (Quick Reference)
================================================================

Open terminal in SHIELD folder, then run:

    venv\Scripts\activate
    streamlit run app.py

That's it.


================================================================
DEACTIVATING THE VIRTUAL ENVIRONMENT
================================================================

When you are done working and want to exit the venv:

    deactivate


================================================================
TROUBLESHOOTING
================================================================

Problem : "python is not recognized"
Fix     : Make sure Python is installed and added to your PATH.
          Download from https://www.python.org/downloads/
          During install, check "Add Python to PATH".

Problem : "venv\Scripts\activate is not recognized"
Fix     : Make sure you are inside the SHIELD folder, not a subfolder.
          Run: cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD"

Problem : Streamlit opens but model fails to load
Fix     : Confirm xgb_shield_model.joblib is inside the model/ folder.
          Confirm you ran streamlit from the SHIELD root, not a subfolder.

Problem : SHAP waterfall plot does not appear
Fix     : Run: pip install --upgrade shap
          Then restart the app.

Problem : Port 8501 already in use
Fix     : Run on a different port:
          streamlit run app.py --server.port 8502


================================================================
GITIGNORE (if using Git)
================================================================

Add a .gitignore file in SHIELD/ with these contents to avoid
committing large or auto-generated files:

    venv/
    __pycache__/
    *.pyc
    .streamlit/
    *.joblib
