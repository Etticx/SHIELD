FIRST-TIME SETUP — run these steps once
================================================================

--- Step 1: Database ----------------------------------------

1a. Open Docker Desktop from the Start menu.
    Wait until the whale icon in the system tray is steady
    (not animating). This takes about 30 seconds.

1b. Open a terminal, navigate to the SHIELD root folder:

        cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD"

1c. Start the PostgreSQL container:

        docker compose up -d

    First time: Docker downloads postgres:15-alpine (~100 MB).
    Subsequent runs: starts instantly from cache.

1d. Confirm it is healthy (wait ~10 seconds after starting):

        docker compose ps

    You should see shield_postgres with STATUS "healthy".
    If it shows "starting", wait a few more seconds and retry.

--- Step 2: Backend -----------------------------------------

2a. Navigate to the backend folder:

        cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD\backend"

2b. Create a virtual environment (first time only):

        python -m venv venv

2c. Activate the virtual environment:

        venv\Scripts\activate

    Your prompt will show (venv) at the start.

2d. Install all Python dependencies (first time only):

        pip install -r requirements.txt

    This installs: fastapi, uvicorn, xgboost, shap, sqlalchemy,
                   asyncpg, groq, pandas, numpy, joblib, etc.

2e. Create your .env file (first time only):

        copy .env.example .env

2f. Open backend\.env in a text editor and add your keys:

    ── Required: Database URL ──────────────────────────────────
    This connects the backend to the Docker PostgreSQL container.
    The credentials match docker-compose.yml exactly.

        DATABASE_URL=postgresql+asyncpg://shield:shield@localhost:5400/shield_db

    Port 5400 is used because 5432 is taken by a local PostgreSQL
    installation, and Windows reserves ports 5433–5532 for Hyper-V/WSL.
    Docker maps its internal 5432 to your machine's 5400 — no conflict.

    ── Optional: Groq API key (AI advisory) ────────────────────
    Get a free key at https://console.groq.com (no billing needed)

        GROQ_API_KEY=your_key_here

    If either key is missing, that feature is disabled gracefully
    and the app still works.
    ─────────────────────────────────────────────────────────────

    then python run.py

--- Step 3: Frontend ----------------------------------------

3a. Open a NEW terminal. Navigate to the frontend folder:

        cd "d:\SCHOLARSHIPS\My Items\Degree Project\FYP\SHIELD\frontend"

3b. Install Node dependencies (first time only):

        npm install

    This may take a minute. Wait for it to complete.

    npm run dev

================================================================
TROUBLESHOOTING
================================================================

Problem : "Application startup failed" / asyncpg password error
Fix     : Docker Desktop is not running or the container is not
          started. Follow these steps in order:
            1. Open Docker Desktop, wait for whale icon to settle
            2. cd "...\SHIELD"
            3. docker compose up -d
            4. docker compose ps  — confirm STATUS is "healthy"
            5. Restart the backend: python run.py

Problem : docker compose ps shows "starting" not "healthy"
Fix     : The container needs more time. Wait 15 seconds and
          run docker compose ps again. If it never becomes
          healthy: docker compose logs db

Problem : "docker is not recognized"
Fix     : Docker Desktop is not installed or not on PATH.
          Install from https://www.docker.com/products/docker-desktop
          then restart your terminal.

Problem : Port binding error / "access permissions" on Docker start
Fix     : Windows (Hyper-V/WSL) reserves large port ranges including
          5433-5532. The docker-compose.yml is already set to use
          port 5400 which is outside all reserved ranges. If you still
          see this error, check excluded ranges with:
              netsh int ipv4 show excludedportrange protocol=tcp
          Then pick any port not in those ranges and update both
          docker-compose.yml and DATABASE_URL in backend\.env.

Problem : Port 5432 already in use (local PostgreSQL conflict)
Fix     : Your local PostgreSQL owns 5432. The docker-compose.yml
          and DATABASE_URL are already set to port 5400 to avoid
          this. If you still see the error confirm backend\.env has:
              DATABASE_URL=postgresql+asyncpg://shield:shield@localhost:5400/shield_db

Problem : /logs page shows "Could not load logs" (503)
Fix     : DATABASE_URL is not set in backend\.env, or Docker is
          not running. Check: docker compose ps

Problem : "No module named 'groq'"
Fix     : Run inside the activated venv:
              pip install "groq>=1.7.0"

Problem : "python is not recognized"
Fix     : Python is not on PATH. Reinstall Python and check
          "Add Python to PATH" during setup.

Problem : venv\Scripts\activate not recognised
Fix     : You are not inside the backend/ folder. Run:
              cd "...\SHIELD\backend"
          then activate.

Problem : "npm is not recognized"
Fix     : Node.js is not installed. Download from https://nodejs.org/

Problem : Frontend shows "Failed to fetch" or API errors
Fix     : The backend is not running. Start Terminal 2 first.
          Check: http://localhost:8000/health

Problem : Backend crashes — model file not found
Fix     : Confirm xgb_shield_model.joblib is in SHIELD/model/
          Check MODEL_PATH in backend\.env:
              MODEL_PATH=../model/xgb_shield_model.joblib

Problem : Port 8000 already in use
Fix     : Edit backend\.env:  PORT=8001
          Edit frontend\.env.local:
              NEXT_PUBLIC_API_URL=http://localhost:8001

Problem : Port 3000 already in use
Fix     : Next.js auto-tries 3001, 3002 etc. Check terminal output.

Problem : SHAP slow on first prediction
Fix     : Normal. TreeExplainer is built once at startup.
          First call takes a few seconds; subsequent calls are fast.

  Complete first-timer walkthrough from zero to running app

WHAT YOU NEED TO UNDERSTAND FIRST
----------------------------------
The project has three parts that all need to run at the same time:

  1. DATABASE  — PostgreSQL stores all evaluation history
  2. BACKEND   — FastAPI (Python) runs the AI model
  3. FRONTEND  — Next.js (Node.js) serves the website

Think of it like three engines. All three must be running before
the app works. You will open three Terminal windows, one for each.

The code lives on GitHub already, so there is nothing to copy from
your Windows machine. You just download it fresh on your Mac.


================================================================
STEP 0 — Tools you need to install (do this once, ever)
================================================================

Open the Terminal app on your Mac.
(Press Cmd + Space, type "Terminal", press Enter)

------- 0a. Homebrew ----------------------------------------
Homebrew is the Mac package manager. It installs everything else.

Paste this entire line into Terminal and press Enter:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It will ask for your Mac password (nothing shows as you type —
that is normal). Press Enter when prompted. Takes ~3 minutes.

After it finishes, it will print two commands starting with
"echo" and "eval". Run BOTH of them. They look like this
(your username will differ):

    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> /Users/YOURNAME/.zprofile
    eval "$(/opt/homebrew/bin/brew shellenv)"

Verify Homebrew works:

    brew --version

You should see something like: Homebrew 4.x.x


------- 0b. Python 3.11 ------------------------------------
macOS ships with an old Python. Install the right version:

    brew install python@3.11

Verify:

    python3.11 --version

You should see: Python 3.11.x


------- 0c. Node.js 20 -------------------------------------

    brew install node@20
    brew link node@20

Verify:

    node --version     <- should show v20.x.x
    npm --version      <- should show 10.x.x


------- 0d. Git --------------------------------------------
Git is probably already on your Mac, but make sure:

    git --version

If it says "command not found", run:

    brew install git


------- 0e. Database: PostgreSQL via Docker (recommended) --

Docker is the cleanest way. Download Docker Desktop for Mac
(Apple Silicon version):

    https://www.docker.com/products/docker-desktop

Download, open the .dmg file, drag Docker to Applications.
Open Docker from Applications. Wait for the whale icon in
your top menu bar to stop animating (~30 seconds).

Verify:

    docker --version

ALTERNATIVE — No Docker (PostgreSQL via Homebrew):
If you do not want Docker at all, run instead:

    brew install postgresql@15
    brew services start postgresql@15

    # Create the database and user:
    psql postgres -c "CREATE USER shield WITH PASSWORD 'shield';"
    psql postgres -c "CREATE DATABASE shield_db OWNER shield;"

Then in your backend .env file use this DATABASE_URL instead:

    DATABASE_URL=postgresql+asyncpg://shield:shield@localhost:5432/shield_db

Note: Homebrew PostgreSQL uses port 5432, not 5400.
      Docker maps to 5400 to avoid conflicts on Windows.
      On a fresh Mac, 5432 is free so we use it directly.

================================================================
STEP 3 — Set up the Backend (Python / FastAPI)
================================================================

Open a NEW Terminal window.
(Right-click Terminal in your Dock → New Window, or Cmd+N)

Navigate to the backend folder:

    cd ~/Documents/SHIELD/backend

Create a virtual environment.
A virtual environment is an isolated Python sandbox — it keeps
the project's Python packages separate from everything else on
your Mac. You only do this ONCE:

    python3.11 -m venv venv

Activate the virtual environment:

    source venv/bin/activate

Your Terminal prompt now shows (venv) at the start.
This tells you the sandbox is active. ALWAYS do this before
running any backend command.

Install all Python dependencies (first time only):

    pip install -r requirements.txt

This installs: fastapi, xgboost, shap, pandas, numpy, groq, etc.
Takes 2–5 minutes. You will see a lot of text scrolling — normal.

Create your .env file (first time only):

    cp .env.example .env

Open the .env file in a text editor to add your keys:

    open -e .env

This opens TextEdit. Set these values:

  If using Docker PostgreSQL (port 5400):
    DATABASE_URL=postgresql+asyncpg://shield:shield@localhost:5400/shield_db

  If using Homebrew PostgreSQL (port 5432):
    DATABASE_URL=postgresql+asyncpg://shield:shield@localhost:5432/shield_db

  Optional (for AI advisory):
    GROQ_API_KEY=your_key_here
    (Get a free key at https://console.groq.com)

Save and close TextEdit.

Start the backend:

    python run.py

You should see:

    INFO  Loading XGBoost model ...
    INFO  Building SHAP TreeExplainer ...
    INFO  Initialising Groq advisory engine ...
    INFO  Database ready — evaluations table confirmed.
    INFO  SHIELD backend ready.
    INFO  Uvicorn running on http://0.0.0.0:8000

Leave this Terminal window open. The backend must keep running.


================================================================
STEP 4 — Set up the Frontend (Next.js)

Open ANOTHER new Terminal window (third one).

Navigate to the frontend folder:

    cd ~/Documents/SHIELD/frontend

Install Node.js dependencies (first time only):

    npm install

You will see a progress bar.

Check the .env.local file to make sure it points at your backend:

You should see:

    NEXT_PUBLIC_API_URL=http://127.0.0.1:8000

Start the frontend:

You should see:

    ▲ Next.js 14.x.x

Leave this Terminal window open too.

================================================================
MAC TROUBLESHOOTING
================================================================

Problem : "brew: command not found"
Fix     : Homebrew did not add itself to your PATH.
          Run the two "echo" and "eval" lines printed at the
          end of the Homebrew installation again.

Problem : "python3.11: command not found"
Fix     : Run: brew install python@3.11
          Then: brew link python@3.11

Problem : "source venv/bin/activate" — no error but no (venv)
Fix     : Make sure you are inside backend/ folder:
              cd ~/Documents/SHIELD/backend
          Then run the activate command again.

Problem : pip install fails with "error: externally-managed-environment"
Fix     : You are using the system Python, not the venv.
          Run: source venv/bin/activate   first.

Problem : Port 5432 already in use
Fix     : You have a local PostgreSQL running. Either stop it:
              brew services stop postgresql@15
          Or use Docker on port 5400 instead.

Problem : Docker "Cannot connect to Docker daemon"
Fix     : Docker Desktop is not open. Open it from Applications
          and wait for the whale icon to stop animating.

Problem : "npm run dev" — "next: command not found"
Fix     : npm install did not run. Run it now:
              cd ~/Documents/SHIELD/frontend
              npm install

Problem : Frontend loads but shows "Failed to fetch"
Fix     : Backend is not running. Go to Terminal 2 and run:
              python run.py
          Then refresh the browser.

Problem : SHAP/numpy build error during pip install
Fix     : You are on Apple Silicon (M1–M4). Some packages
          build from source. Make sure Xcode tools are installed:
              xcode-select --install
          Then retry: pip install -r requirements.txt

Problem : git pull shows merge conflicts
Fix     : You have local uncommitted changes. Reset to match GitHub:
              git fetch origin
              git reset --hard origin/master
          WARNING: This discards any local edits you made.
